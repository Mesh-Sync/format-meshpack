# Governance Model

This document outlines the governance model for the Standard MeshPack project.

## Maintainers

The project is maintained by the MeshSync team.

**Lead Maintainer**:
- Jordane Masson (@JordaneMasson) - `contact@meshsync.net`

Maintainers are responsible for:
- Reviewing and merging Pull Requests.
- Managing releases and versioning.
- Enforcing the Code of Conduct.
- Steering the technical direction of the format.

## Decision Making

Decisions are made by consensus among maintainers. Significant changes to the specification require a Request for Comments (RFC) process.

## RFC Process (Request for Comments)

For substantial changes to the `.meshpack` format or schemas, an RFC is required.

1.  **Draft**: Open a Pull Request adding a file to `definition/proposals/RFC-000-title.md`.
2.  **Discussion**: The community discusses the proposal on the PR.
3.  **Approval**: Maintainers vote. Simple majority required.
4.  **Implementation**: Once approved, the spec is updated and SDKs are regenerated.
